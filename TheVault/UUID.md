- `UUID` (Universally Unique ID), it is used to generate unique values without coordination
- It might look like a string but it's not a string but a completely separate type `UUID`
	```sql
  >>> CREATE TABLE uuid_example(
  >>> uuid UUID
  >>> );
  CREATE TABLE
  >>> INSERT INTO uuid_example (uuid ) VALUES ('5d41402a-bc4b-2a76-b971-9d911017c592');
  INSERT 0 1
	```
	it's length is 16 bytes
	```sql
  >>> SELECT uuid, pg_typeof(uuid), pg_column_size(uuid) FROM uuid_example ;
                  uuid                 | pg_typeof | pg_column_size
  --------------------------------------+-----------+----------------
  5d41402a-bc4b-2a76-b971-9d911017c592 | uuid      |             16
  (1 row)
	```

- you can typecast the `UUID` into `TEXT`, but that occupies more than twice the space, i.e., `40 bytes`
	```sql
  >>> SELECT pg_column_size(uuid), pg_column_size(uuid::TEXT) FROM uuid_example ;
  pg_column_size | pg_column_size
  ----------------+----------------
              16 |             40
  (1 row)
	```

- To generate random `UUID`, you can use
	```sql
  >>> SELECT gen_random_uuid();
            gen_random_uuid
  --------------------------------------
  d7d757e9-a75f-4e1d-a8e1-5fba24b2de76
  (1 row)
	```

- You can use `v7 uuid` (not available in `postgres` by default, might be some extension for it) as `primary key` as it increases over time and good for index-trees, whereas completely random `uuid` (generated by `gen_random_uuid` function of `postgres`) doesn't have this.
