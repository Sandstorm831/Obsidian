- difference between `x86`, `x86_64`m `x64` and `arm` based processor architectures

| Name  | also-called     | Bit width | Key features                                           |
| ----- | --------------- | --------- | ------------------------------------------------------ |
| `x86` | 32 bit `x86`    | 32 bit    | original 32 bit intel architecture                     |
| `x64` | `x86_64`, AMD64 | 64 bit    | 64-bit extension of `x86`                              |
| `arm` | `arm64`         | 64 bit    | completely different architecture for power efficiency |
